# ECO-0412 / ASLCTL-163 — lift sensor software support

Release candidate for engineering approval. P/N 55-1180-1 replaces 55-1180-0 at
body ASL2-26-04100 and later, and on earlier bodies during service retrofits.

## Image selection

The existing four chassis variant names remain the 55-1180-0 images. Append
`_eco0412` for 55-1180-1. For example:

```bash
cmake -S . -B build-target-eco0412 \
  -DCMAKE_TOOLCHAIN_FILE=cmake/arm-none-eabi.cmake \
  -DASL200_VARIANT=asl200_electric_mack_eco0412
cmake --build build-target-eco0412
# asl200_fw_asl200_electric_mack_eco0412.elf / .hex
```

Do not flash the default legacy variant onto a new-sensor body. There is no serial
input or sensor-identification message in the current interface. Sensor identity
cannot be inferred from a midrange voltage (both parts output 2500 mV at 80°).
For retrofits, installed sensor identity overrides original serial effectivity.
Keep the chassis name, sensor suffix, software commit and installed part number
together in manufacturing and service release records. Release owners must assign
the production software version and approve the ECO before shipping.

## Software impact

- New lift conversion: −20 + (mV − 500) × 200 / 4000 degrees. Legacy remains
  −20 + mV × 200 / 5000. Motion limits and tuning remain in degrees.
- Low/high faults remain SPN 520200, FMI 4/3 at <250/>4750 mV after 50 ms;
  raw invalid readings immediately inhibit motion. Existing legacy thresholds
  are preserved. Electrical engineering must confirm legacy documentation and
  treatment of the new sensor's 250–500/4500–4750 mV shoulders.
- ARM_SENSORS retains raw 1 mV/bit and the full 0–5000 mV wire range for faults.
  ARM_POSITION remains calibrated degrees. DBC comments, diagnostics and I/O
  documentation describe both sensor families.
- SIL models each part's physical transfer function. Scenario coverage includes
  all existing interlocks, limits, stalls, dropout and a new short-to-supply case.
- Reach sensor, angular endpoints, mechanical mount and connector are unchanged.

## Replay and bench use

Use the matching variant for `tools/replay_log.py --variant ...`, `sil.runner`
and `sil.matrix`. Historical 55-1180-0 logs retain their original variant names;
new-sensor logs and retrofits use the `_eco0412` name. The viewer embeds the
resolved hardware/controls parameters in each trace. The HIL adapter remains a
stub; bench calibration, supplier tolerances and real supply-ratiometric behavior
require hardware validation outside this repository.
